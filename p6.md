## 2. Work items (do in order)

### 2.1 `pipeline/stage_series.py` — the stage

New file mirroring `pipeline/stage_resolve.py` structure.

- **Signature:** `run_series(settings: Settings, *, force: bool, limit: int | None) -> int` using
  `owned_session_db(settings, session, db)`.
- **Exit codes:** `0` ok, `1` stage failure / robots-denied. No session-expiry code needed here —
  `/ediciones/` is public (not gated). If a `SessionExpiredError` still surfaces, treat it as a stage
  failure (`close_run('failed')`, return 1).
- **Pre-flight:** `RobotsPolicy.from_session(...)`; if `not policy.is_allowed('/ediciones/')` → log
  error, return 1 (mirror `stage_lists`).
- **Run bookkeeping:** `run_id = create_run(db, "series")` then `db.commit()`.
- **Series selection:**
  - default: `get_pending_series(db)` (pending only; E4 — failed excluded unless forced)
  - `force=True`: union of pending + failed + completed → `get_all_series(db)` (see 2.2)
  - `limit`: slice the selection (same pattern as `stage_resolve`)
- **Per-series loop:**
  1. `response = session.get(series.url)` → `raise_for_status()`.
  2. `parsed = parse_series_page(response.text, whakoom_series_id=..., slug=..., url=...)`.
  3. In **one** `with db.transaction():`
     - `publisher_id = upsert_publisher(db, parsed.publisher)` (by name; G1-deferred) — may be
       `RecordMissingError`? No — publisher upsert inserts or returns existing; tolerate `None` when
       the page has no publisher.
     - `series_id = upsert_series(db, parsed, publisher_id)` → surrogate id.
     - Stamp volumes: `for v in parsed.volumes: v.series_id = series_id` (**required** —
       `upsert_volumes` raises `ValueError` if `series_id is None`, repositories.py:549).
     - `upsert_volumes(db, parsed.volumes)`.
     - Authors: `for a in parsed.authors: author_id = upsert_author(db, a); link_series_author(db, series_id, author_id, a.role)`.
     - `insert_observation(db, Observation(series_id=series_id, run_id=run_id, rating=parsed.rating, ...))`.
     - (Observation insert is the "one row per (series, run)" guarantee — `UNIQUE(series_id, run_id)`.)
  4. On any `STAGE_ERRORS` member or `RecordMissingError`: log warning, `set_series_status(db, series_id, 'failed')`
     (outside the failed transaction), increment `items_failed`, **continue**.
- **End:** `close_run(db, run_id, 'completed', items_processed=..., items_failed=..., notes=...)`,
  `db.commit()`, return 0.

### 2.4 Tests — `whakoom_scraper/tests/test_pipeline_series.py`

MockTransport + temp DB, pattern from `test_pipeline_resolve.py` / `test_pipeline_list_detail.py`.

- **Happy path:** one series → `series.scrape_status == 'completed'`; volumes/authors/junction/
  observation rows written; exactly 1 observation.
- **Required-field failure:** page missing a required field → series `failed`, stage continues,
  `close_run` reports `items_failed >= 1`.
- **`--force`:** completed series re-scraped; exactly one **new** observation per series (0 duplicate
  errors on re-run).
- **`--limit`:** caps the number of series fetched (assert request count).
- **robots-denied:** policy returns denied for `/ediciones/` → stage returns 1, no series scraped.
- **transient error:** one series raises `httpx.TransportError` → marked `failed`, others still
  processed.
